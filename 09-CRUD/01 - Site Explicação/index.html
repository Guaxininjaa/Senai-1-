📦 O que é um Array?

Um array é uma estrutura de dados que guarda uma coleção de itens em uma única variável. Cada item é chamado de elemento, e cada elemento tem uma posição chamada índice, que começa em 0. 

const dinossauros = ["T-Rex", "Triceratops", "Velociraptor"];
//  índice:             0            1               2

Sem array, você precisaria de uma variável para cada valor:

// Ruim 👎
const dino1 = "T-Rex";
const dino2 = "Triceratops";
const dino3 = "Velociraptor";

// Bom 👍
const dinossauros = ["T-Rex", "Triceratops", "Velociraptor"];

🎯 Acessando elementos

Use colchetes com o índice para pegar um elemento:

console.log(dinossauros[0]); // "T-Rex"
console.log(dinossauros[2]); // "Velociraptor"

// Descobrir quantos elementos tem:
console.log(dinossauros.length); // 3

// Pegar o ÚLTIMO elemento (truque útil!):
console.log(dinossauros[dinossauros.length - 1]);

🔁 Percorrendo um array

Com o for que você já conhece:

for (let i = 0; i < dinossauros.length; i++) {
    console.log(dinossauros[i]);
}

Ou com forEach, que executa uma função para cada elemento:

dinossauros.forEach(function(dino) {
    console.log(dino);
});

🛠️ Os 14 métodos de array

➕ Adicionar elementos

1. push() adiciona no FINAL

dinossauros.push("Spinosaurus");
// ["T-Rex", "Triceratops", "Velociraptor", "Spinosaurus"]

2. unshift() adiciona no INÍCIO

dinossauros.unshift("Stegosaurus");
// ["Stegosaurus", "T-Rex", "Triceratops", "Velociraptor"]
➖ Remover elementos

3. pop() remove o ÚLTIMO

const removido = dinossauros.pop();
console.log(removido); // "Velociraptor"
// ["T-Rex", "Triceratops"]

4. shift() remove o PRIMEIRO

const removido = dinossauros.shift();
console.log(removido); // "T-Rex"
// ["Triceratops", "Velociraptor"]
✂️ Cortar e emendar

5. splice() remove/adiciona em QUALQUER posição

Formato: splice(posição, quantosRemover, novoItem)

// Remove 1 elemento na posição 1:
dinossauros.splice(1, 1);
// ["T-Rex", "Velociraptor"]

// Substitui o elemento da posição 1:
dinossauros.splice(1, 1, "Pteranodon");
// ["T-Rex", "Pteranodon"]

6. slice() copia um pedaço (NÃO altera o original)

Formato: slice(início, fim) — o fim NÃO entra na cópia.

const copia = dinossauros.slice(0, 2);
console.log(copia); // ["T-Rex", "Triceratops"]
// O array original continua igual!
🔍 Buscar informações

7. indexOf() EM QUAL POSIÇÃO está?

console.log(dinossauros.indexOf("Triceratops")); // 1
console.log(dinossauros.indexOf("Barney"));      // -1 (não existe)

8. includes() EXISTE ou não? (true/false)

console.log(dinossauros.includes("T-Rex"));  // true
console.log(dinossauros.includes("Barney")); // false
🔄 Reorganizar

9. sort() ordena (A → Z)

dinossauros.sort();
// ["T-Rex", "Triceratops", "Velociraptor"] em ordem alfabética

10. reverse() inverte a ordem

dinossauros.reverse();
// ["Velociraptor", "Triceratops", "T-Rex"]
⚡ Métodos avançados (com funções)

11. forEach() executa algo para CADA elemento

dinossauros.forEach(function(dino, indice) {
    console.log(indice + ": " + dino);
});
// 0: T-Rex
// 1: Triceratops
// 2: Velociraptor

12. map() cria um NOVO array transformado

const maiusculas = dinossauros.map(function(dino) {
    return dino.toUpperCase();
});
// ["T-REX", "TRICERATOPS", "VELOCIRAPTOR"]

13. filter() cria um NOVO array só com quem passa no teste

const nomesGrandes = dinossauros.filter(function(dino) {
    return dino.length > 6;
});
// ["Triceratops", "Velociraptor"]

14. reduce() reduz tudo a UM único valor

const notas = [8, 7.5, 9, 6.5];
const soma = notas.reduce(function(total, nota) {
    return total + nota;
}, 0);
console.log(soma);                // 31
console.log(soma / notas.length); // 7.75 (média)
