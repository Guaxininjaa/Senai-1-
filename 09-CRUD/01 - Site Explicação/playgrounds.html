Laboratórios interativos: os 14 métodos de array

⬅️ Teoria push/pop shift/unshift splice slice indexOf/includes forEach map filter reduce sort/reverse Quiz Desafio

1️⃣ push() e pop() — o FINAL do array

O push() adiciona no final e retorna o novo tamanho. O pop() remove do final e retorna o elemento removido.

2️⃣ unshift() e shift() — o INÍCIO do array

O unshift() adiciona no início e retorna o novo tamanho. O shift() remove do início e retorna o elemento removido. Repare como TODOS os índices mudam!

3️⃣ splice() — o canivete suíço ✂️

Formato: splice(posição, quantosRemover, novoItem). Remove, adiciona ou substitui em QUALQUER posição, e retorna um array com os removidos.

4️⃣ slice() — copiar sem estragar 🍕

Formato: slice(início, fim) — copia do índice início ATÉ o fim (sem incluir o fim!), e NÃO altera o original.

5️⃣ indexOf() e includes() — buscando 🔍

O indexOf() responde ONDE está (ou -1 se não existe). O includes() responde SE existe (true/false).

6️⃣ forEach() — visitando cada elemento 🚶

O forEach() executa uma função uma vez para cada elemento, recebendo o elemento e o índice. Ele não cria array novo e não retorna nada — só "visita".

7️⃣ map() — transformando tudo 🔄

O map() cria um array NOVO aplicando uma transformação em cada elemento. O novo array tem SEMPRE o mesmo tamanho do original.

9️⃣ reduce() — tudo vira UM valor 🧮

O reduce() percorre o array acumulando um resultado, e no final devolve um único valor. Perfeito pra somas, médias e totais.
